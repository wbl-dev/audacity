## 当前完成状态

Workbench 已完成当前阶段的在线入口和开发工具删减：

- 产品在线服务使用本地 stub，保留 Diagnostics、崩溃恢复和可选 Crashpad。
- 顶部导航不再显示 DevTools Tab，Workbench 不注册 `audacity://devtools`。
- 即使开启 developer mode，也不会恢复 Workbench 的 DevTools Tab。
- Workbench 配置关闭 TestFlow；当前生成的 Ninja 构建图不包含 `muse_testflow` 或 `testflowrunner`。
- 顶部 Diagnostics 菜单只保留诊断文件导出。
- 故意触发崩溃的测试按钮不作为 Workbench 产品入口。
- 默认 Audacity Profile 继续保留原有 DevTools、TestFlow 和诊断菜单行为。

## 最终验证记录

在 Qt 6.11.3、AppleClang 17 和 Xcode 26.2 SDK 环境下：

- `cmake --build build/workbench-debug --parallel 8`：通过，最终为 `ninja: no work to do`。
- Workbench 及受影响测试集：14/14 通过。
- `trackedit_tests`：串行单跑通过，并在最终完整 CTest 中通过。
- 完整 CTest：41 个测试程序中 40 个通过。
- `git diff --check`：通过。

唯一失败程序仍是 `au_project_tests`，其内部 49 个用例中 46 个通过，以下三个既有用例失败：

- `ClipTempoPersistenceTests.ProjectTempoChangeStretchesImportedClips`
- `ClipTempoPersistenceTests.EnablingStretchToTempoChangesLocksTheClipOntoTheProjectTempo`
- `ClipTempoPersistenceTests.ProjectTempoChangesScaleAMatchingClip`

这些失败不在本轮导航和产品 Profile 清理范围内。本轮没有修改 project tempo、track edit 或音频算法代码。

验证期间曾误让两个完整 CTest 实例重叠运行，它们争用同一个生成式 SQLite 测试文件 `src/trackedit/tests/data/empty_working.aup4`，造成一次瞬时 `trackedit_tests` 失败。日志明确显示一个进程在另一个进程持有数据库时将文件 unlink；改为串行执行后，该测试单独及全量运行均通过。不要并发运行两个完整 CTest 实例。

## 明天在公司继续

已有本地仓库时：

```bash
git fetch wbl
git switch feature/wbl/online-entry-cleanup
git pull --ff-only wbl feature/wbl/online-entry-cleanup
git submodule update --init --recursive
```

新工作区可从 Fork 直接克隆：

```bash
git clone --recurse-submodules --branch feature/wbl/online-entry-cleanup \
  https://github.com/wbl-dev/audacity.git
cd audacity
```

首次配置或 Qt 路径变化后：

```bash
cmake --preset workbench-debug --fresh \
  -DCMAKE_PREFIX_PATH=/Users/your-name/Qt/6.11.3/macos \
  -DQt6_DIR=/Users/your-name/Qt/6.11.3/macos/lib/cmake/Qt6
cmake --build build/workbench-debug --parallel 8
```

如果 CMake 选中了 Command Line Tools 的错误 SDK，按 [`building.md`](building.md) 的说明让 `DEVELOPER_DIR`、`SDKROOT` 和 `CMAKE_OSX_SYSROOT` 指向同一套完整 Xcode；不要把本机绝对 SDK 路径提交到共享 Preset。

启动应用：

```bash
build/workbench-debug/src/app/audacity.app/Contents/MacOS/audacity
```

先执行受影响测试：

```bash
ctest --test-dir build/workbench-debug --output-on-failure \
  -R '^(workbench_.*|appshell_tests|shared_tests|app_tests)$'
```
