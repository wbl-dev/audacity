# Contributing to AGu

AGu is an independent audio editor built on the Audacity 4 codebase. Contributions should preserve local project compatibility with `.aup3` and `.aup4` and keep the application independent from Audacity product services.

## Development

Read [BUILDING.md](BUILDING.md) for dependencies, configuration, and test commands. Keep changes focused and include the tests or manual verification that demonstrate the behavior. Preserve upstream copyright notices and the licenses of retained code.

## Reports and proposals

Use the issue templates in this repository to report reproducible bugs and propose features. Include the AGu version, operating system, steps to reproduce, and a sample project when useful. Do not send AGu reports to the Audacity issue tracker or support forum.

## AI assistance

Read [AI_POLICY.md](AI_POLICY.md) and disclose substantial AI assistance in the pull request and relevant commits.
