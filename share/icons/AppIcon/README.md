# AGu application icon

`AGu.png` is the approved golden hamster artwork (H4), created with
OpenAI imagegen. Preserve its composition, rounded tile, and transparent margin
when exporting other sizes.

The `AGu_AppIcon_*` files provide Qt, Linux, Windows, and package icons.
`AGu_AppIcon.icns` is bundled directly on macOS so that
Icon Composer materials do not change the approved artwork.
