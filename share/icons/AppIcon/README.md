# OnlyAudios application icon

`OnlyAudios.png` is the approved golden hamster artwork (H4), created with
OpenAI imagegen. Preserve its composition, rounded tile, and transparent margin
when exporting other sizes.

The `AU4_AppIcon_*` filenames are retained for existing Qt, Linux, Windows, and
packaging references. `AU4_AppIcon.icns` is bundled directly on macOS so that
Icon Composer materials do not change the approved artwork. The legacy
`AppIcon.icon` bundle is not used by the application target.
